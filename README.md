# SpendWise - Budget and Expense Tracker

SpendWise is a responsive web application designed to help
users track their income, manage daily expenses, and
visualize their personal budget in real-time.

## Live Links
* Netlify Live App: https://pocketbudget-tracker.netlify.app
* GitHub Pages: https://farahabdihassan2-design.github.io/Spendwise/

## Technologies Used
* HTML5 for semantic page structure
* CSS3 (Flexbox and Grid) for responsive styling
* JavaScript (ES6) for state management and interactivity
* Git and GitHub for version control
* Netlify for continuous deployment and static hosting

## Deployment Pipeline and Process
This project is continuously deployed using modern static
hosting platforms:
1. Version Control: Managed via Git and hosted on GitHub
   (https://github.com/farahabdihassan2-design/Spendwise).
2. Hosting and CI/CD: Connected directly to Netlify,
   enabling automated builds and instant deployments on
   every push to the main branch.
3. Static Hosting: Configured with index.html at the root
   level for fast, reliable delivery across global content
   delivery networks.

## Challenges Encountered and Lessons Learned
* Challenge: Customizing the default Netlify subdomain
  from a random hash while ensuring automated build triggers
  remained active and correctly synced with GitHub.
* Lesson Learned: Maintaining a clean root-level directory
  structure with index.html directly at the root completely
  removes the need for complex build scripts or custom
  redirect rules, ensuring zero-configuration deployments.
